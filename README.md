# 🚎Sleeper Bus Ticket Booking System
Developing a web-based flow for a sleeper bus booking service operating between Ahmedabad and Mumbai.

## Web Flow Description

The Web Flow allows users to:
1. Visit the booking website
2. Select a service/product
3. Choose date & time
4. Enter user details
5. Book a Meal option if wanted
6. Review booking summary
7. Complete payment
8. Receive booking confirmation
